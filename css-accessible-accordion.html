FAQ Accordion

Open a question to reveal its answer. This uses native HTML and works with a keyboard.

What is HTML?

HTML provides the structure and meaning of content on a web page.

What is CSS?

CSS styles page elements, including layout, colours, spacing, and responsive behaviour.

What does JavaScript do?

JavaScript adds behaviour and interactivity, such as responding to clicks and updating content.

Can multiple answers stay open?

Yes. Native <details> elements can stay open independently. Add the same name attribute to make them behave as a group in modern browsers.
