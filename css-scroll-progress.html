Keep scrolling.

A tiny, accessible scroll progress indicator built with JavaScript and CSS.

The ideaHow it worksTry it

01 — The idea

A reading progress bar gives people a quick sense of how much of an article remains. It is especially useful for long tutorials, documentation, and blog posts.

This demo places a slim gradient bar at the very top of the page. Scroll down and watch the bar grow as you move through the content.

02 — How it works

The browser exposes the current scroll position through window.scrollY. The maximum scroll distance is the document height minus the viewport height.

Divide the current position by that maximum distance, multiply by 100, and use the result as the bar's CSS width. The example also listens for resize events so it remains accurate when the viewport changes.

For performance, production sites can schedule visual updates with requestAnimationFrame or use a throttled scroll handler.

03 — Try it

Resize your browser, jump to a section using the navigation, or scroll slowly. The progress indicator should update to match your reading position.

You can customize the height, gradient, and position in the CSS. Try changing the gradient to a single color, or placing the indicator at the bottom of the viewport.

Practice challenge

Add a percentage label, make the bar keyboard-reader friendly with an appropriate progress semantic, or create a back-to-top button that appears after the user scrolls.
