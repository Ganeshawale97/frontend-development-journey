What is HTML?

HTML structures content on the web using elements such as headings, paragraphs, links, and forms.

What does CSS do?

CSS controls the visual presentation of a page, including colors, spacing, layout, and responsive styles.

Why use semantic elements?

Semantic elements describe the meaning of content and can improve accessibility and maintainability.
