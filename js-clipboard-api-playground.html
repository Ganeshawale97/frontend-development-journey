Clipboard API Playground

Copy text to the system clipboard or paste clipboard text into the editor. Clipboard permissions are controlled by your browser.

Choose an action. Clipboard access works on secure pages (HTTPS or localhost) in supported browsers.

Manual fallback:

If clipboard access is blocked, select the text above and use your device's Copy or Paste command. This avoids silently pretending that a blocked clipboard action succeeded.

Try these experiments

  • Edit the text, then copy it and paste it into another app.
  • Copy a sentence outside this page, then use Paste from clipboard.
  • Open the browser's site permissions to see how clipboard access is handled.

Reading clipboard contents may require a permission prompt or a recent user gesture. The page never reads the clipboard automatically.
