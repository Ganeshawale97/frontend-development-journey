How it works

The visibilitychange event fires when the browser changes the document's visibility state. Apps use this to pause videos, stop unnecessary animations, or reduce background work.

This demo counts time only while tracking is active. Browsers may throttle timers in background tabs, so the visibility event is used to account for the transition.
